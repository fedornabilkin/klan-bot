# Правила Klan Bot

- Репозиторий самодостаточен: не импортируйте исходники и конфигурацию из соседних репозиториев или служебных каталогов.
- Worker отвечает за доставку обновлений. Проверки членства, доступа, профили и сессии принадлежат API.
- Не выводите токен, Authorization header, полный URL Telegram, тело сообщения и исходные исключения HTTP-клиента в журнал.
- Offset сохраняется только после подтверждения API. Ошибка обработки или записи offset не означает успех; повторите доставку.
- Запускайте только один worker на один Telegram token. Обработка должна переживать повторную доставку.
- Для shutdown используйте AbortSignal, освобождайте таймеры и сетевые запросы.
- Файлы сборки, запуска, deployment, проверки и документацию храните и версионируйте в этом репозитории. Docker build context — корень этого репозитория.
- Реальные секреты, offset, журналы и временные результаты не коммитьте. Локальные данные можно хранить в игнорируемом `.local/` или во внешнем постоянном каталоге; в контейнере используйте volume. `.env.example` содержит только пустые значения и безопасные примеры.
- Проверяйте изменения через `npm test`, `npm run typecheck`, `npm run build`. Реальные сообщения и изменения в Telegram допустимы только по явному запросу пользователя.
